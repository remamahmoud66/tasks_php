SERENITY SPA - Spa Treatment Booking System
===========================================

How to run (XAMPP):
1) Copy the folder "spa_booking" into  C:\xampp\htdocs\
2) Start Apache and MySQL from the XAMPP Control Panel.
3) Open http://localhost/phpmyadmin -> Import -> choose database.sql -> Go.
4) Open db.php and check DB_PORT (3307 like our class example, or 3306 - the XAMPP default).
5) Open http://localhost/spa_booking/

Accounts:
  Admin    : admin@spa.com     / admin123
  Customer : sara@example.com  / customer123

Folders:
  images/   starting images (paths are saved in the database)
  uploads/  images uploaded by the admin
  docs/     ER diagram and screenshots
